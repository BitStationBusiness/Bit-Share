# Bit-Share v1.0.3

Corrección completa de identidad visual en Windows.

## Corregido

- Bit-Share usa el AppUserModelID `com.bitstation.bitshare` antes de crear la
  ventana, evitando la identidad genérica de Flutter en Windows.
- El icono oficial se establece de forma explícita para la ventana y el botón
  de la barra de tareas.
- Se mantienen el icono oficial en el ejecutable y el instalador.

## Archivos

- `Bit-Share-v1.0.3.apk`: APK Android firmado.
- `Bit-Share-Setup-1.0.3.exe`: instalador Windows x64 en `C:\Bit-Share`.
- `SHA256SUMS.txt`: hashes de integridad SHA-256.
