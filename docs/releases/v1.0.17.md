# Bit-Share v1.0.17

## Editor adaptable

- La previsualización de vídeos verticales y horizontales se limita de forma
  proporcional al espacio disponible; los controles quedan accesibles mediante
  desplazamiento en Windows y Android.
- El editor muestra ahora el tiempo exacto de reproducción y una barra para
  buscar dentro del tramo seleccionado.
- La rotación se refleja inmediatamente en la previsualización y mantiene la
  misma dirección que el archivo exportado.
- La vista de reproducción de la galería usa el mismo ajuste seguro para no
  desbordar una ventana pequeña.

## Validación

- `flutter analyze`, pruebas Dart y compilación Windows completados.
