# Bit-Share v1.0.2

Corrección visual para Windows.

## Corregido

- El ejecutable Windows, su título de ventana, el icono de la barra de tareas
  y el instalador usan el icono oficial azul/morado de Bit-Share en lugar del
  icono predeterminado de Flutter.

## Archivos

- `Bit-Share-v1.0.2.apk`: APK Android firmado.
- `Bit-Share-Setup-1.0.2.exe`: instalador Windows x64 en `C:\Bit-Share`.
- `SHA256SUMS.txt`: hashes de integridad SHA-256.
