# Bit-Share v1.0.7

Release de interfaz para Windows.

## Mejoras

- La ventana Windows abre en un formato compacto de `440 × 500` píxeles
  lógicos, pensado para pegar un enlace sin ocupar media pantalla.
- El contenido usa un ancho máximo de 520 px, menos márgenes y tarjetas más
  finas para mantener una interfaz portátil y fácil de usar.
- La lista de opciones se desplaza dentro de la ventana; no agranda el marco
  cuando se analiza un vídeo con muchas resoluciones.
- El usuario aún puede redimensionar la ventana entre un mínimo útil y un
  máximo compacto de `560 × 760` píxeles lógicos.

## Archivos

- `Bit-Share-Setup-1.0.7.exe`: instalador Windows x64 en `C:\Bit-Share`.
- `SHA256SUMS.txt`: hash de integridad SHA-256.
