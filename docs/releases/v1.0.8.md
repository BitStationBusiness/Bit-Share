# Bit-Share v1.0.8

Corrección de flujo para Windows.

## Mejoras

- Se eliminan los botones **Pegar** y **Analizar** de la pantalla principal.
- Al pulsar `Ctrl+V`, Bit-Share toma el enlace del portapapeles y lo analiza
  automáticamente.
- La tecla Enter sigue disponible para analizar un enlace escrito a mano.
- El campo de enlace ocupa todo el ancho de la interfaz compacta.

## Archivo

- `Bit-Share-Setup-1.0.8.exe`: instalador Windows x64 en `C:\Bit-Share`.
- `SHA256SUMS.txt`: hash SHA-256 de integridad.
