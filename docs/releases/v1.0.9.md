# Bit-Share v1.0.9

Corrección de experiencia tras descargar contenido.

## Mejoras

- Windows limpia el enlace y las opciones analizadas cuando una descarga
  termina, dejando visible únicamente el resultado.
- Windows añade **Copiar al portapapeles** junto a **Mostrar en Descargas**
  para copiar la ruta del archivo creado.
- Android abre la aplicación de Galería del teléfono en lugar del gestor de
  archivos.
- Los nuevos vídeos y audios de Android se indexan en los álbumes
  `Movies/Bit-Share` y `Music/Bit-Share` para que la Galería los encuentre.

## Archivos

- `Bit-Share-Setup-1.0.9.exe`: instalador Windows x64 en `C:\Bit-Share`.
- `Bit-Share-v1.0.9.apk`: APK Android firmado.
- `SHA256SUMS.txt`: hashes SHA-256 de integridad.
