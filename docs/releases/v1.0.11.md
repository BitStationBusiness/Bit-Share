# Bit-Share v1.0.11

## Android

- El botón **Galería** abre ahora directamente la aplicación de galería visual del dispositivo, en lugar del gestor de archivos.
- En dispositivos HONOR se abre específicamente la Galería de HONOR, que presenta los contenidos de Bit-Share como álbum con miniaturas.
- Se mantiene una resolución dinámica para usar la app de galería disponible en otros dispositivos Android.

## Windows

- Se conserva la interfaz compacta y las mejoras de la versión anterior.
