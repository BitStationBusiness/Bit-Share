# Bit-Share v1.0.18

## Editor más fluido y compacto

- La textura de vídeo nativa de Windows se compone directamente, sin una capa
  de caché que pueda retrasar la presentación de nuevos fotogramas.
- El cabezal de reproducción ahora está integrado en la misma línea de tiempo
  del recorte; los extremos siguen delimitando el fragmento exportado.
- El tiempo actual, la duración y los límites del recorte se leen desde una
  única cabecera compacta.
- Volumen, silencio, velocidad, rotación y calidad usan filas densas para que
  los controles importantes queden visibles sin espacio desperdiciado.

## Validación

- `flutter analyze` y pruebas Dart completados antes del empaquetado.
