# Bit-Share v1.0.14

## Windows: descargas fallaban en los primeros intentos

- yt-dlp, ffmpeg y deno recién instalados pueden tardar varios segundos en su
  primera ejecución (por ejemplo, mientras Windows los analiza la primera
  vez) y yt-dlp puede necesitar descargar su solucionador de retos JS desde
  GitHub la primera vez que hace falta. Ambas cosas podían superar el tiempo
  de espera interno y mostrar "No se pudo conectar con el sitio" aunque el
  enlace fuera perfectamente válido — y solo funcionaba tras reintentar
  manualmente varias veces.
- El análisis del enlace y la descarga ahora reintentan automáticamente
  hasta dos veces ante este tipo de fallo, antes de mostrar cualquier error.
  Si aun así hace falta un reintento, la interfaz lo indica ("Conexión
  inestable, reintentando…") en lugar de quedarse sin respuesta.
- Se añadió un indicador de progreso mientras se analiza un enlace, que
  antes no mostraba ninguna señal de actividad.
