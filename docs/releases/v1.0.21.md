# Bit-Share v1.0.21

## Vista previa fluida y edición precisa

- En Windows, los vídeos AV1, VP9 y VP8 generan automáticamente una copia
  temporal H.264 optimizada para la previsualización del editor.
- La copia temporal conserva la frecuencia de fotogramas y la duración del
  original. El archivo descargado y la exportación nunca se sustituyen.
- La caché se reutiliza al volver a abrir el mismo vídeo y elimina entradas
  antiguas automáticamente.
- La línea temporal de recorte es ahora un único control interactivo: permite
  pulsar o arrastrar el cabezal de reproducción y mover por separado los
  límites inicial y final.
- Al desplazar el cabezal, el vídeo se pausa, actualiza la imagen y continúa si
  estaba reproduciéndose.

## Ventana Windows

- Se retiró el límite artificial de tamaño máximo: maximizar vuelve a ocupar
  toda la pantalla y Windows puede acoplar Bit-Share a cualquiera de los
  laterales.
- El editor incorpora pantalla completa real mediante su botón o la tecla
  `F11`, conservando el tamaño y la posición anteriores al salir.
- Se mantiene un tamaño mínimo compacto para evitar controles inutilizables.

## Validación

- El proxy se validó con un vídeo AV1 real de 30 FPS: la salida H.264 conserva
  exactamente 30 FPS y la misma duración.
- Análisis estático, pruebas Dart y compilación nativa Windows completados.
