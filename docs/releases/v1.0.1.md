# Bit-Share v1.0.1

Primera release pública de Bit-Share para Android y Windows.

## Incluye

- APK Android firmado con la clave de publicación de BitStation.
- Instalador Windows 64-bit creado con Inno Setup.
- Instalación por defecto de Windows en `C:\Bit-Share`.
- Runtime local de Windows incluido: yt-dlp, FFmpeg y Deno.
- Selector de audio o vídeo, resoluciones disponibles, progreso, cancelación y
  comprobación de espacio.
- Sesión de navegador opcional en Windows cuando un sitio compatible exige
  autenticación.

## Archivos

- `Bit-Share-v1.0.1.apk`: instalador Android.
- `Bit-Share-Setup-1.0.1.exe`: instalador Windows x64.
- `SHA256SUMS.txt`: hashes de integridad SHA-256.

## Nota de uso responsable

Utiliza Bit-Share para contenido propio, autorizado o permitido por su fuente.
No elimina DRM, no sortea pagos y no accede a contenido privado sin la
autorización correspondiente.
