# Bit-Share v1.0.13

## Galería in-app (Android y Windows)

- El icono de lanzador y el botón "Galería" tras una descarga abren ahora una
  galería propia de Bit-Share (grid, reproducción y un editor ligero de
  recorte/mute) en lugar de la Galería del sistema.
- Android añade un `GalleryPlugin` nativo respaldado por MediaStore y
  exportación por FFmpeg embebido.
- Windows reutiliza las mismas pantallas contra el runtime ffprobe/ffmpeg
  existente.

## Descargas Windows: enlaces de álbum/playlist

- Un enlace de álbum o playlist (por ejemplo, un álbum de YouTube Music)
  descargaba todas las pistas pero la interfaz solo informaba de un archivo,
  dejando el resto sin avisar. Ahora el análisis detecta la playlist, suma
  los tamaños estimados de todas las pistas y el resultado final indica
  cuántos archivos se guardaron.
- Cualquier fallo de red durante el análisis o la descarga ofrece un botón
  **Reintentar** que reutiliza el enlace ya analizado, sin tener que
  volver a pegarlo.

## Archivos

- `Bit-Share-Setup-1.0.13.exe`: instalador Windows x64 en `C:\Bit-Share`.
- `Bit-Share-v1.0.13.apk`: APK Android firmado.
- `SHA256SUMS.txt`: hashes SHA-256 de integridad.
