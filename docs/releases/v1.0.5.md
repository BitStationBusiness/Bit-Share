# Bit-Share v1.0.5

Descarga de Stories de Facebook e Instagram, y login con navegador integrado
para contenido que requiere sesión.

## Nuevo

- Descarga de Stories de Facebook: captura de video y audio DASH con mux
  automático.
- Descarga de Stories de Instagram con el mismo flujo que Facebook.
- Navegador integrado en Android para iniciar sesión cuando el contenido
  está detrás de autenticación.

## Archivos

- `Bit-Share-v1.0.5.apk`: APK Android firmado.
- `Bit-Share-Setup-1.0.5.exe`: instalador Windows x64 en `C:\Bit-Share`.
- `SHA256SUMS.txt`: hashes de integridad SHA-256.
