# Bit-Share v1.0.20

## Reproductor mejorado

- La barra temporal ahora es un control deslizante real con una zona de
  interacción amplia y arrastre continuo en Windows y Android.
- Durante el arrastre, la posición se actualiza inmediatamente y el vídeo se
  reanuda automáticamente si estaba reproduciéndose.
- Se muestran el tiempo actual y la duración total.
- Se añadieron botones para retroceder y avanzar 10 segundos.
- En Windows funcionan los atajos `Espacio`, `Flecha izquierda` y
  `Flecha derecha` para reproducir, pausar y desplazarse.
- La barra superior y el panel de reproducción usan un diseño más compacto y
  consistente con el editor renovado.

## Validación

- Análisis estático, pruebas Dart y compilaciones Android/Windows completados.
