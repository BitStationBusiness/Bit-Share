# Bit-Share v1.0.15

## Editor multiplataforma

- El resultado de una descarga ofrece **Editar**, **Galería** y **Compartir**
  inmediatamente en Android; Windows ofrece las mismas acciones desde su
  panel de finalización.
- El editor permite recortar con precisión, ajustar volumen entre 0 % y 200 %,
  silenciar vídeo, cambiar velocidad, rotar y escoger la calidad de salida.
- La previsualización respeta los límites del recorte y la exportación guarda
  una copia nueva para conservar intacto el archivo original.
- Android y Windows mantienen el mismo plan FFmpeg para que los ajustes de
  velocidad y volumen se apliquen juntos correctamente.
- En Windows, Compartir coloca el archivo real en el portapapeles para pegarlo
  directamente en WhatsApp, Telegram, correo u otra aplicación compatible.

## Validación

- Pruebas Dart y análisis estático sin incidencias.
- Compilación Kotlin de Android y compilación Windows verificadas.
- Exportación FFmpeg de prueba con recorte, velocidad y volumen combinados.
