# Bit-Share v1.0.16

## Windows

- El diálogo de actualización es ahora más compacto: usa un ancho máximo de
  320 px, encabezado en una sola línea y espaciado reducido durante la
  descarga.
- El editor ya no queda vacío cuando la previsualización del reproductor no
  admite el códec del vídeo. Los controles de recorte, volumen, velocidad,
  rotación y exportación permanecen disponibles para FFmpeg.
- Se validan proporciones de vídeo inválidas para impedir que un valor del
  reproductor oculte todo el contenido de la pantalla de edición.

## Validación

- Pruebas Dart y análisis estático sin incidencias.
- Compilación Windows verificada.
